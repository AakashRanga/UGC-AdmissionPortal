3. Authentication
To use the API, you need to pass an authentication token in the header.
Header Parameter
APIKey: {Your_Authentication_Token}
Headers
Authentication Token: A token required for authentication. This must be passed in the header to validate the request.

Query Parameter
DEB Unique ID: The unique identifier for a student. This parameter is required and must be passed as a query parameter.
